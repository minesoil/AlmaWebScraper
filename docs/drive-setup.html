Connect a study folder

Google Cloud setup is required once for this website. Keep the study folder private.

  1. Open Google Cloud Console and create or select a project.
  2. Enable the Google Drive API in that project.
  3. In Google Auth Platform, configure the app name, contact information and audience. For personal testing with an external audience, add the Google account that owns or can read the hub as a test user.
  4. Add the scope https://www.googleapis.com/auth/drive.metadata.readonly in Data Access. This allows metadata access across the account. Compass uses it to browse the chosen study folder and its subfolders.
  5. Create an OAuth client of type Web application. Add https://minesoil.github.io as an authorized JavaScript origin. For local development, also add http://localhost:8000. Origins have no repository path. The browser token flow uses a popup.
  6. Copy the client ID ending in .apps.googleusercontent.com into Google Drive setup in Compass. Also paste the private study hub folder link. Click Save setup, then Connect Google Drive.
  7. Choose the account with access to the hub and review Google's consent screen. Browse course folders and select files to include in a study request.

The client ID identifies the app and can be entered in Compass. Any client secret stays outside the website. Access tokens stay in memory and expire. Reloading requires reconnection. Disconnect clears the session and revokes the current grant. To remove a grant separately, use the connected-app settings in the Google account.

Setup is stored in this browser, separately from assignment backups. File names and selections stay in memory. The app reads metadata and opens source files in Drive. Automatic file-content ingestion and cloud backup are future work.

Use the existing ChatGPT connection

Enter a question, select source files and build a study request. Review the text, copy it, and paste it into ChatGPT. This transfers only the reviewed text when pasted. ChatGPT must open the selected sources through its own Drive connection before answering from their contents.
